Detailed Description

Lista dwukierunkowa z dostępem do obu końców oraz iteratorem.

Klasa jest właścicielem swoich węzłów. Kopiowanie jest zabronione, aby uniknąć wielokrotnego zwalniania tej samej pamięci.
